# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities using
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
on this repository (Security tab → "Report a vulnerability"). Do not open a
public issue for security reports.

## No secrets in this repository

`chipgraph` is a public repository. It must never contain:

- secrets, API keys, tokens or credentials;
- internal or NDA data;
- files from private projects.

Examples and fixtures use open-source IP and PDKs only. If you find secrets or
private data committed to the history, report it the same way as a
vulnerability (private reporting), not as a public issue.
