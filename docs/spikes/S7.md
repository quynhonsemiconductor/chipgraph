# S7 — Runtime `claude-code`: the task loop, role subagents, a write guard, tokens

**Question (IMPLEMENTATION_PLAN.md):** can the user's own Claude Code drive chipgraph's
loop `next_task` → a role subagent → `submit`, with the subagent limited in tools and
model, a `PreToolUse` hook refusing writes outside the task's `outputs`, several
subagents in parallel, and token use readable afterwards? It gates M1-11 (D35).

**Status:** harness ready and checked without a model. The real run is **not done yet**:
it uses the lead's Claude plan and waits for the lead's go-ahead (and, for Sonnet
subagents, the weekly Sonnet reset on 2026-10-03 20:00 Asia/Saigon).

## Harness (`docs/spikes/s7/`)

| File | Role |
|---|---|
| `s7_server.py` | Throwaway MCP server (`MCPServer`, stdio): `next_task` (hands out two tasks at once), `get_context` (spec + `outputs`), `submit` (every changed file must be an output of a dispatched task; outputs must exist; Verilator lint). Writes `.s7/allowed.json` for the hook |
| `hook_guard.py` | `PreToolUse` command hook for `Write|Edit|MultiEdit|NotebookEdit`: denies (`permissionDecision: deny`) any path not in `.s7/allowed.json`; logs every decision with `agent_id`/`agent_type` to `.s7/hook.log` |
| `run.sh` | Copies tinysoc to `OUT` (default `/tmp/s7-run`), writes the `rtl-author` subagent (tools `Read, Write, Edit, Glob, Grep, get_context`; no Bash; `model: $SUB_MODEL`), the hook in `.claude/settings.json`, and runs one `claude -p` with `--max-turns`, `--strict-mcp-config`, `--output-format stream-json`, OpenTelemetry metrics to the console |
| `report.py` | Summarises a run: tool calls, `Agent` calls, hook allow/deny, submit results, turns, duration, `total_cost_usd`, `usage`, `modelUsage` |
| `selftest.py` | Plays the agents' part (no model): tasks, context, hook allow/deny/outside-the-project, submit accept/reject |

Task `t2` asks, on purpose, for a README line outside its `outputs`: the hook must
refuse it and `submit` must still accept the task once only `rtl/tiny_sat.sv` changed.

## Verified without a model (2026-09-30)

- `selftest.py`: next_task returns both tasks; get_context gives the outputs; the hook
  allows `rtl/tiny_pulse.sv`, denies `README.md` and a path outside the project, ignores
  `Read`; submit accepts a lint-clean output and rejects a change outside the outputs
  and a missing output.
- The hook as a real subprocess, JSON on stdin, prints the documented deny object and
  logs `agent_type`.
- Hook input/decision format checked against the Claude Code hooks reference: file
  tools get an absolute `tool_input.file_path`; hooks from settings files run inside
  subagents too, with `agent_id`/`agent_type`; `-p` sessions treat the folder as trusted,
  so the project's `.claude/settings.json` hook runs. Subagent **frontmatter** hooks do
  not run in `-p` (workspace trust), which is why the guard lives in settings.
